المفهوم التقني — Web App vs Website
HealPath ليس موقعاً إلكترونياً — بل تطبيق ويب متكامل بتجربة Single Page App وحالة مستخدم كاملة وبيانات محفوظة داخل Docker.

التفاعليةصفحات ثابتة✓ تجربة تفاعلية كاملة بدون إعادة تحميل
حالة المستخدممحدودة✓ Session كامل + ملف شخصي + إشعارات حية
البياناتخارجية✓ محفوظة داخل Docker Volume محلي

الميزات الكاملة
6.1 إدارة حسابات المرضى والحجوزات
  • تسجيل: بريد + كلمة مرور + اسم + هاتف
  • ملف المريض الشخصي (التاريخ المرضي)
  • عرض الأطباء مع صورهم وخبراتهم
  • حجز موعد مع الطبيب المختار
  • الدفع نقدي عند الوصول (المرحلة الأولى)
  • إشعارات تذكير عبر البريد الإلكتروني
6.3 المساعد الطبي الذكي — الميزة المحورية ⭐
المسار 1 — تحليل الأعراض
Flow
المريض: "عندي ألم في الركبة"
       ↓ GPT-4
الرد:   قسم العظمية ← توجيه
        + زر "احجز موعداً الآن"
        ⚠️ تحليل استرشادي فقط
المسار 2 — قراءة التحاليل
Flow
المريض: يرفع صورة نتيجة تحليل
       ↓ GPT-4 Vision
الرد:   قراءة أولية للقيم
        + توصية بالقسم
        ⚠️ تحليل استرشادي أولي
المرحلة الثانية (مستقبلاً): تحليل الأشعة X-Ray / MRI بنماذج Computer Vision متخصصة — مؤجّل للمرحلة الثانية.

تحليل السوق — سوريا
📊 واقع السوق
  • السوق في مرحلة نمو مبكر للتحول الرقمي
  • غالبية المستشفيات تعتمد أنظمة تقليدية أو ورقية
  • طلب متزايد على الخدمات الصحية الرقمية
  • انتشار الإنترنت والهواتف في المدن الكبرى
🚀 الفرصة السوقية
  • غياب تام لحلول ذكاء اصطناعي في السوق المحلي
  • لا منافس يجمع: توجيه ذكي + حجز + صيدلية
  • حاجة فعلية لتسهيل الوصول للخدمات الطبية

تحليل SWOT
💪 نقاط القوة — Strengths
  • • ذكاء اصطناعي متكامل (GPT-4)
  • • 4 أدوار بصلاحيات محددة
  • • نموذج إيراد مرن بالعمولة
  • • Docker مكتفٍ ذاتياً تماماً
⚠️ نقاط الضعف — Weaknesses
  • • فريق فردي — وقت تطوير أطول
  • • اعتماد على API خارجي (OpenAI)
🚀 الفرص — Opportunities
  • • سوق غير مشبع بالحلول الذكية
  • • لا منافسة بذكاء اصطناعي
  • • طلب حقيقي ومتزايد
🔥 التهديدات — Threats
  • • تحديات الدفع الإلكتروني (مؤجّلة)
  • • متطلبات تنظيمية طبية
  • • مقاومة التحول الرقمي

مخطط قاعدة البيانات
USERS — المرضى
  • idUUID PK
  • name, emailVARCHAR
  • password_hashbcrypt
  • phoneVARCHAR
  • created_atTIMESTAMP
HOSPITAL_STAFF — موظفو المستشفى
  • idUUID PK
  • name, emailVARCHAR
  • roleENUM(admin,doctor,pharmacy,hr)
  • department_idFK → DEPARTMENTS
  • specialization, bioTEXT
  • photo_pathVARCHAR
APPOINTMENTS — الحجوزات
  • idUUID PK
  • patient_idFK → USERS
  • doctor_idFK → HOSPITAL_STAFF
  • appointment_dateDATE
  • statusENUM(pending,confirmed,completed,cancelled)
  • notesTEXT
MEDICINES — الأدوية
  • idUUID PK
  • name, scientific_nameVARCHAR
  • priceDECIMAL
  • stock_quantityINTEGER
  • image_pathVARCHAR
  • is_availableBOOLEAN
ORDERS — طلبات الصيدلية
  • idUUID PK
  • patient_idFK → USERS
  • statusENUM(pending,confirmed,delivered,cancelled)
  • delivery_typeENUM(pickup,delivery)
  • total_priceDECIMAL
AI_CONVERSATIONS — المساعد الذكي
  • idUUID PK
  • patient_idFK → USERS
  • typeENUM(symptoms,lab_result)
  • input_textTEXT
  • ai_responseJSONB
  • recommended_departmentVARCHAR

docker-compose.yml (مقتطف)
services:
  postgres:
    image: postgres:16-alpine
    volumes:
      - postgres_data:/var/lib/postgresql/data
  api:
    build: ./backend
    volumes:
      - uploads:/app/uploads
    depends_on: [postgres]
  frontend:
    build: ./frontend
    depends_on: [api]
  nginx:
    image: nginx:alpine
    ports: ["80:80", "443:443"]

متغيرات البيئة
.env.example
# قاعدة البيانات
DATABASE_URL=postgresql://healpath_user:PASSWORD@postgres:5432/healpath_db
DB_PASSWORD=your_secure_password

# المصادقة
JWT_SECRET=your_jwt_secret_key
JWT_EXPIRES_IN=7d

# OpenAI
OPENAI_API_KEY=sk-...

# البريد الإلكتروني
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=hospital@email.com
SMTP_PASS=email_password

# تخزين الملفات (محلي في Docker)
UPLOADS_PATH=/app/uploads
MAX_FILE_SIZE=10mb

# البيئة
NODE_ENV=production
PORT=3001

أوامر التشغيل
bash
# بيئة التطوير
docker-compose up -d

# إنشاء قاعدة البيانات والجداول
docker-compose exec api npx prisma migrate dev

# بيئة الإنتاج
docker-compose -f docker-compose.prod.yml up -d

# نسخة احتياطية لقاعدة البيانات
docker-compose exec postgres pg_dump -U healpath_user healpath_db > backup.sql

# تحديث التطبيق
docker-compose pull && docker-compose up -d --build
